# skills

A set of agent skills for managing my life.

## Skills

| Skill | Purpose |
| --- | --- |
| [github-first](skills/github-first/) | Whenever a task touches GitHub, use the `gh` CLI immediately before anything else. |
| [obsidian-cli](skills/obsidian-cli/) | Interact with Obsidian vaults using the `obsidian` CLI — read, create, search, and manage notes, tasks, and properties. |
| [obsidian-development](skills/obsidian-development/) | Develop and debug Obsidian plugins and themes — reload, errors, screenshots, DOM/CSS inspection, and `eval`. |

## Layout

Each skill lives in `skills/<skill-name>/SKILL.md` with YAML frontmatter (`name`, `description`) followed by its instructions.
